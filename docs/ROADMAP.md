# Roadmap — IncidentOps

Hitos de evolución de producto y operaciones, en orden incremental.

| ID | Hito | Objetivo / cierre |
|---|---|---|
| H001 | Triaje multi-interfaz | Clasificar y enrutar reportes de forma determinista, sin persistencia, con consumo inmediato desde web y terminal. |
| H002 | Resumen de incidentes activos | Consultar incidentes activos e incumplimientos de SLA, con filtrado por componente, desde web y terminal. |
| H003 | Ciclo de vida, duplicados y SLA | Registrar incidentes entrantes de forma persistente, alertar si existe otro equivalente abierto y auditar el SLA en cualquier instante de referencia. |
| H004 | Persistencia relacional dedicada y runtime en contenedores | Ejecutar el servicio de forma reproducible en contenedores con base de datos relacional dedicada y verificación operativa real de conectividad. |
